# THE SLOP gazetteer — V7

Public-facing encyclopedia remains Wikipedia-inspired with Times New Roman. The approved members-only chat has been restyled with a ChatGPT-inspired charcoal UI, conversation bubbles, sidebar, and rounded composer.

## Deploy
Replace the files in your existing GitHub repository with the contents of this ZIP (preserving folder paths), commit, and wait for Vercel to deploy. Keep your existing Vercel Supabase environment variables. No database migration is required for these UI-only changes.

## Security
Messages are restricted by your Supabase policies; they are not end-to-end encrypted. Keep the service role key private.
